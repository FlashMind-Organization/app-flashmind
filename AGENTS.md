# FlashMind Mobile — Orientação para Agentes

## Contexto do App

Aplicativo Flutter mobile de repetição espaçada e baralhos. Opera local-first via `AppScope`.
- Consulte o vault em `../docs-flashmind/` para entender o impacto em telas antes de alterar modelos.
- Execute `flutter analyze` e `flutter test` para validar mudanças de código.
